# 🎬 Movie Maker – Full-Stack GraphQL Application

A full-stack **Movie Maker web application** built from scratch using **GraphQL, Apollo, ReactJS, Node.js, and MongoDB**. This project demonstrates how to design and implement a modern, scalable API and connect it to a dynamic frontend using Apollo Client.

The application allows users to create, manage, and query movie-related data efficiently using GraphQL, showcasing the advantages of a single endpoint, flexible queries, and efficient data fetching compared to traditional REST APIs.

---

## 🚀 Project Overview

This project was built to showcase real-world **full-stack development** skills using modern JavaScript technologies. It focuses on:

* Designing a GraphQL API with Apollo Server
* Connecting a React frontend using Apollo Client
* Managing data with MongoDB and Mongoose
* Building reusable UI components and handling client-side state
* Creating a clean, scalable project structure suitable for production-ready applications

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/movie-maker-graphql.git

# Install backend dependencies
cd server
npm install

# Install frontend dependencies
cd ../client
npm install
```

### Run the Application

```bash
# Start backend
cd server
npm run dev

# Start frontend
cd client
npm start
```
